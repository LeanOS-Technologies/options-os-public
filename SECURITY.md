# Security policy

Do not report vulnerabilities in Options OS through a public GitHub issue.

Email **bella@leanos.tech** with:

- a concise description of the issue;
- the affected component or repository area;
- reproduction steps or supporting information;
- the potential impact;
- any known mitigation.

Do not include credentials, API keys, customer information, private repository content or proprietary specifications in public issues, discussions or pull requests.
